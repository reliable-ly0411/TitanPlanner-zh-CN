# PLAN 本地计划预览

在 PLAN 的任务页结束单元格编辑后，按 **Ctrl+M** 打开独立的只读窗口。二维俯视图和三维视图采用同一份规划。更新或清空计划后再次按 Ctrl+M。修改计划、切换机体或关闭窗口后，旧预览会撤下。

窗口支持同一 UTM 分区内的普通航点（WAYPOINT），包括绝对高度、相对该计划 Home 和相对地形的高度。选择本地高程清单后，两个视图才会一起显示。缺少数据、样本无效或遇到暂未支持的命令时，窗口会显示原因。图中的地形标记表示航点位置上的高程样本，不提供连续地表或净空结果。

## 准备本地高程清单

清单为 UTF-8 JSON。绝对航点和 Home 采用 WGS84 十进制度，经纬度须与当前规划一致。高程为 EGM96 正高米值，须由掌握数据来源的人员核对。软件检查清单与当前数值是否匹配，清单由使用方负责审核其来源。不要从旧任务文件的 frame 编号推定垂直基准。下面的坐标和高度仅用于说明格式。

```json
{
  "schema": "TitanPlanner.PlanPreview.EGM96.v1",
  "planSource": "已审核的测绘记录或计划高度依据及其版本",
  "home": {"latitude": 10.12, "longitude": 2.10, "metres": 120},
  "absolute": [
    {"latitude": 10.121, "longitude": 2.101, "metres": 145}
  ],
  "terrainProduct": null,
  "tiles": {}
}
```

无需 Home 证明时，`home` 可填 `null`。没有绝对高度航点时，`absolute` 可填空数组。只用相对地形高度时，`planSource` 也可填 `null`。源清单可包含多个普通绝对航点的证据，短计划可以使用同一清单中仍匹配的部分。

相对地形高度使用 [USGS EROS SRTM 1 Arc-Second Global](https://doi.org/10.5066/F7PR7TFT) 的本地 HGT。将经审核的原始 HGT 放在清单目录，`terrainProduct` 填 `USGS:10.5066/F7PR7TFT`，`tiles` 列出每块 HGT 的原始文件名和 SHA-256，例如 `"N10E002.hgt": "64位十六进制SHA-256"`。支持标准 3601 × 3601 栅格和南纬 50° 至北纬 50° 内的每度瓦片，单次预览最多读四块。只读取本地文件，不下载瓦片。清单摘要锁定用于预览的字节，数据来源应与供应方记录核对。
