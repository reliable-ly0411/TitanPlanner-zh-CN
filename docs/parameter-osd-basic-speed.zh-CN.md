# OSD 四屏基础速度显示说明

补充七个已登记的正式固件版本中 OSD1～OSD4 的 48 个参数键，共 336 条分版说明。只增加增强简中的阅读说明，参数值、选项、位置、传感器读数及飞行行为不变。

- `GSPEED`：显示 GPS 地速；`VSPEED`：显示爬升率。
- `ASPD1`、`ASPD2`：分别显示主、副空速传感器直接报告的空速，不涉及融合策略或传感器选择。
- `EN` 保留原显示开关 0/1；`X`、`Y` 只说明原屏幕横向和纵向位置，原范围分别保持 0–59、0–21。不增加默认位置、阈值或设置建议。

每条按机型、版本、原键和完整原记录指纹匹配。固定来源与完整 SHA-256 见[来源登记](../localization/parameters/sources.json)。
